# Политика конфиденциальности приложения «Сусеки»

Действует с 24 ноября 2026 г. · [English version](en/)

«Сусеки» (в английском интерфейсе — «BTW») — общий список покупок для семьи. У приложения нет своего сервера и учётных записей: всё, что вы вводите, хранится на вашем телефоне и, если вы подключили синхронизацию, на вашем собственном сетевом хранилище Synology NAS. Разработчик не получает, не собирает и не хранит ваши данные.

## К каким версиям относится политика

Политика действует для всех версий приложения «Сусеки» / «BTW» (Android-пакет `org.koda.shopping`), как бы вы его ни установили:

- **RuStore** — версия, установленная из магазина RuStore;
- **GitHub** — APK-файл со страницы выпусков проекта на GitHub;
- **iPhone** — версия для iOS.

Версии отличаются только способом обновления (см. «Сторонние компоненты и обновления»); данные во всех версиях обрабатываются одинаково.

## Какие данные обрабатывает приложение

| Данные | Зачем | Где хранятся |
|---|---|---|
| Списки покупок, товары, отметки «куплено», история изменений | Основная функция | На телефоне; при синхронизации — на вашем NAS |
| Имя в семье, цвет отметок, грамматический род («добавил»/«добавила»), фото профиля (по желанию) | Показывать членам семьи, кто что добавил и купил | На телефоне; при синхронизации — на вашем NAS |
| Адрес NAS, QuickConnect ID, логин и пароль DSM, токен доверенного устройства (2FA), отпечатки доверенных сертификатов | Подключение к вашему NAS | Только на телефоне, в зашифрованном системном хранилище (Android Keystore / iOS Keychain); не попадают в резервные копии |
| Случайный идентификатор установки | Отличать файлы этого телефона от файлов других устройств семьи на NAS | На телефоне и в именах файлов на вашем NAS |
| Голос (только пока вы диктуете) | Голосовой ввод товаров | Приложение не записывает и не хранит звук, см. ниже |

Приложение не собирает геолокацию, контакты, рекламные идентификаторы и не показывает рекламу.

## Синхронизация через Synology NAS

Синхронизация необязательна: без неё приложение работает только на одном телефоне. Если вы подключаете NAS, приложение обращается напрямую к нему (в локальной сети или через интернет) и сохраняет файлы в папке «Shopping List» домашней папки пользователя DSM. Доступ к этим файлам есть у всех, кто входит под этой учётной записью DSM, — обычно это ваша семья. Приложение не создаёт учётных записей DSM.

Если вы указали QuickConnect ID, приложение запрашивает адрес вашего NAS у службы QuickConnect компании Synology (global.quickconnect.to) и, если нужно, соединяется через её ретранслятор. Для поиска NAS в локальной сети используется mDNS/Bonjour — запросы не выходят за пределы вашей сети.

## Голосовой ввод

Речь распознаёт системная служба телефона, а не приложение. На iPhone распознавание выполняется на устройстве, если оно это поддерживает; иначе запись обрабатывает Apple. На Android распознавание выполняет служба, выбранная в системе (обычно Google или Яндекс); в зависимости от устройства и настроек звук может передаваться этой службе. Приложение получает только текст. Разрешение на микрофон можно не давать — всё остальное будет работать.

## Камера и фото

Фото профиля вы выбираете сами — снимком или из галереи. Приложение получает только выбранное изображение.

## Сторонние компоненты и обновления

- **Версия из RuStore** использует RuStore In-app Updates SDK (ООО «ВК») для проверки и установки обновлений. Этот SDK включает модули аналитики и метрик RuStore, которые могут передавать в RuStore технические данные о работе обновления и устройстве; их обработку регулирует [политика RuStore](https://www.rustore.ru/help/legal/).
- **Версия с GitHub** проверяет наличие обновлений на GitHub (github.com); при этом GitHub, как любой веб-сервер, видит IP-адрес телефона.
- **Версия для iPhone** сама обновления не проверяет.

Других SDK (аналитики, рекламы, отчётов о сбоях) в приложении нет.

## Хранение и удаление

Данные хранятся, пока вы их не удалите. Удалённые товары помечаются как удалённые и исчезают из файлов синхронизации примерно через 30 дней; история изменений на телефоне хранится 7 дней.

- Удалить данные с телефона: удалите приложение или очистите его данные в настройках системы.
- «Выйти из DSM» в профиле удаляет с телефона логин и пароль; «Забыть» рядом с «Этот телефон запомнен» удаляет токен доверенного устройства.
- Данные на NAS удаляются удалением папки «Shopping List» в File Station.

## Дети

Приложение не предназначено специально для детей и не собирает данные о возрасте.
